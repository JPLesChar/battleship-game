# 🚢 Battleship 8×8

A fast-paced Battleship game designed for short, addictive matches.

Unlike the traditional 10×10 version, this game uses an 8×8 board, making each match quicker, more dynamic, and beginner-friendly. No instructions are needed: place your shots, sink the enemy fleet, and enjoy rapid gameplay directly in your browser.

## Features

- ✅ Fast 8×8 gameplay
- ✅ Smart computer opponent
- ✅ Extra turn after a successful hit
- ✅ Sunk ships automatically marked
- ✅ Sound effects
- ✅ Mobile-friendly design
- ✅ No installation required

## Play Online

https://jpleschar.github.io/battleship-game/

## Technologies

- HTML
- CSS
- JavaScript

## Goal

Sink all enemy ships before the computer sinks yours. Every hit matters, and every game can be completed in just a few minutes.

Enjoy the battle!
